## 1. Native map (MapKit, local Capacitor plugin)
- Swift plugin `FFMapPlugin` (CAPPlugin + CAPBridgedPlugin, Capacitor 8 API) in ios/App/App/, registered by a `CAPBridgeViewController` subclass (`capacitorDidLoad` → `bridge?.registerPluginInstance`), set as the storyboard's view controller customClass. Add files to the Xcode project properly (project.pbxproj) so `xcodebuild` compiles them.
- MKMapView placed as a subview of the WKWebView's `scrollView` at the slot's document rect, so it scrolls natively with the page (no JS scroll sync). JS sends the rect (from getBoundingClientRect + scrollY, in CSS px = points) on show, on resize/orientation, and after layout changes (ResizeObserver on #spots-map). Native masks the map so it never draws over the sticky header or the floating tab bar (JS sends header bottom and tab-bar top in viewport coords; native updates the mask on scroll via contentOffset KVO).
- Satellite-hybrid map type, region fit to the spots with padding, rounded corners matching the slot (22 pt). Pins: MKMarkerAnnotationView tinted by verdict (GO green #34D399, MAYBE amber #FBBF24, SKIP red #F87171, none grey); favourite = star glyph; closed piers = grey with a "Closed" subtitle (closureBadge). Selected pin enlarged. Tapping a pin dispatches `ffmap:select` {id} into the page (evaluateJavaScript or bridge.triggerJSEvent with document target).
- Hide/fade the map (alpha, 150 ms) when a sheet opens or a tab swipe starts; JS side in ios/bridge.js observes `#sheet-root` children and the existing `v5:tab`/swipe events and calls hide/show. Fully remove from view hierarchy on `hide()`; no leaks on repeated show/hide (verify with 30 cycles).
- No location permission needed (do not set showsUserLocation). Dark/Night/Light: MKMapView overrideUserInterfaceStyle follows the page theme (data-theme).
- ios/bridge.js defines `window.FFNativeMap = { show, hide }` only when the plugin is available.
