# V5 to concept mesh map

The concept supplies the visual language and page hierarchy. V5 remains the source of product behavior, labels, and evidence. This map records where each existing V5 information unit lives in the redesigned five-tab app.

| Current V5 element | Redesigned location | Preservation notes |
| --- | --- | --- |
| Today verdict seal and GO / MAYBE / SKIP certainty states | Fishing Outlook hero card below the photo and conditions strip | Keep verdict and confidence/qualifier language; concept letter grades are not used. |
| Today headline and one-line reason | Fishing Outlook card | Keep the existing copy and reason semantics. |
| Best bet and backup | Fishing Outlook card and the following Best Fishing Windows / detail sections | Keep best and alternate spot, mode, and window context. |
| Targets and suitability bars | Species row on Today; expanded targets in the lower Today details; species cards and detail sheet | Suitability stays a conditions fit, never a catch chance. Preserve target order and accessible numeric labels. |
| “How this is decided” / why | Expandable explanation in lower Today details | Preserve factor explanations and the distinction between supporting and limiting evidence. |
| Confidence and certainty reasons | Expandable section in lower Today details | Keep current confidence wording and stale-data qualification. |
| Local history and historical trip rates | Today target details and Species detail sheet | Keep sample-size caveats and month/mode context. |
| Best-times scrubber, legend, and selected-hour detail | Best Fishing Windows curve card on Today | Restyle the existing scrubber as a draggable curve; retain selection, window markers, legend, hourly suitability, species-at-hour detail, and unavailable states. |
| Today-versus-tomorrow comparison | Lower Today detail sections; Plan day chips and daily outlook | Keep the comparison and its copy in V5 terms. |
| Alerts and banners | Existing global banner region and relevant Today/Spots details | Keep safety alert priority and visible messages. |
| Stale, offline, cached, sample, and fallback labels | Freshness chip and existing banners/source details | Never hide or soften data provenance or staleness. |
| Source attributions and data availability | Expandable Data & Sources card on Today; Credits is reserved for image attributions | Preserve data source links and missing/stale source summaries. |
| Spot picker and scope controls | Header spot pill and searchable spot sheet; Spots tab search/filter | Preserve current scope, mode, and return-to-report actions. |
| Spots list, verdicts, targets, and favorites | Map slot / web list header, selected spot card, then full filterable spot list | Favorites sort first; map selection updates the shared spot scope. |
| Spot detail sheet | Selected spot card plus View Details sheet | Keep verdict, target species, mode, window, and directions. |
| Species detail sheet and setup content | Species carousel, large image, segmented detail tabs, and species detail sheet | Preserve season/mode, setup, techniques, bait/gear, best times, local history, eligibility reason, and FWC link. |
| Species eligibility, fit word, and historical trip rate | Species cards and detail sheet | Realistic candidates rank first; retain the fit word even when a candidate is dimmed, and use reason-specific labels rather than “Rare” for off-list species. |
| Plan days 1–2 windows | Plan day chips, Daily Outlook, and selected-day details | Preserve forecast windows and their GO/MAYBE/SKIP semantics. |
| Plan days 3–7 outlook semantics | Plan day chips and selected-day outlook | Keep outlook-only language; do not present these days as run-backed verdicts. |
| Catch Log, stats, entries, and export | Log tab | Keep add/edit/detail/delete, stats, CSV export, and empty state. |
| More sheet | ⋯ sheet | Keep appearance selection, local notifications when native support exists, favorites management, share, Credits, and data notes. |
| Theme choice | Appearance in More; Dark/Night/Light palettes | Preserve Auto/Dark/Night/Light behavior and reduced-motion preferences. |
| Live refresh and local cache | Header refresh button, freshness chip, and offline banners | Keep existing refresh and cached-report behavior. |
