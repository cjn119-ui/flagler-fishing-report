# V5 historical-rate threshold sheet — proposals for architecture owner

**Status: proposed input for architecture review; not approved model parameters.** This sheet describes MRIP reported catch rates only. It makes no claim about species behavior or spot-level success.

## Definition and provenance

- **Catch definition:** version 1; unique interview `(YEAR, WAVE, ID_CODE)` is a hit for a species if a mapped row has `CLAIM > 0 AND F_BY_P == 1`, or `HARVEST > 0`, or `RELEASE > 0`. Alias hits are unioned per interview. `TRIP.CATCH` is not the outcome. Bait/forage/unknown exclusions remain in the any-fish measure; catalog species rates follow their exact `species.js` aliases.
- **Source years:** 2015–2025; NOAA MRIP Access Point Angler Intercept Survey, Florida shore records in Duval, Flagler, Nassau, and St. Johns; ocean slice shared by surf/pier, inland slice used by inshore.
- **Proxy handling:** primary counts/rates exclude rows marked `imputed_proxy` by trip/catch `IMP_REC == 1` or embedded interview year differing from survey year. Every table shows the proxy-inclusive sensitivity rate as well.
- **Grain:** each annual/monthly `n` is the unique interview denominator for that mode/time slice, not species-specific respondent counts. A species `hits/n` is its per-interview union count. No Kish effective sample size is included.

## Proposed values for architecture review

| Parameter | Proposed value | Proposal rule |
|---|---:|---|
| Common band | shrunk monthly rate ≥ 0.20 | Carry forward the architecture baseline; report all species-month cell counts below. |
| Occasional band | 0.05 ≤ shrunk monthly rate < 0.20 | Carry forward the architecture baseline; rates use all surveyed interviews as denominator. |
| Rare band | shrunk monthly rate < 0.05 | Complement of the two higher bands; zero rate remains Rare when the history slice is available. |
| Realistic-target floor | 0.05 | Retain the 1-in-20 floor as a candidate only; final use remains contingent on the real-observation coverage gate. |
| `kNeighbor` | 80 interviews | Keep the existing worked-example strength as an explicit prior-equivalent sample size; no fishing-behavior calibration is claimed. |
| `kMonth` | 40 interviews | Keep the existing worked-example strength as an explicit prior-equivalent sample size; no fishing-behavior calibration is claimed. |

Shrinkage equations used to count proposed bands (not a launch validation): `pAnnual=hAnnual/nAnnual`; `pNeighbor[m]=(hPrev+hNext+80*pAnnual)/(nPrev+nNext+80)` with Dec/Jan wrap; `pMonth[m]=(hMonth+40*pNeighbor[m])/(nMonth+40)`. Band counts below use `pMonth` and include only cells with an available monthly denominator.
