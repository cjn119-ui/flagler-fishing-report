      How windows are picked

      Each 30-minute daylight slot is scored: tide movement 35%, sunrise/sunset light 25%, wind 20%, rain chance 20%. Windows are the best non-overlapping 2-hour stretches. This ranks the forecast, it is not a bite forecast.
